## Executive Summary

High transaction volume across financial services clients suffered from high false-positive fraud declines (14%) and processing latencies exceeding 2 seconds.

We architected a real-time streaming feature store and gradient-boosted ensemble pipeline on **Azure ML** that scored over 1.2M daily financial transactions with &lt; 180ms p95 latency, reducing false positives from 14% to 3.5%.

---

## Architecture & Real-Time Feature Store

1. **Streaming Feature Engine**: Ingested high-frequency transaction events, computing rolling window aggregation metrics (e.g. 5-minute velocity, geographical distance jumps).
2. **Ensemble Scoring Engine**: Combined LightGBM models with real-time feature validation microservices.
3. **Automated Feature-Drift Detection**: Triggered automated alerting and retraining jobs whenever statistical distribution shift exceeded Kolmogorov-Smirnov test thresholds.

---

## Results & Production Impact

- **1.2M+ Daily Scored Events**: Handled peak bursts of 250 requests/second with zero dropped events.
- **91% Latency Reduction**: Cut p95 response time from 2,100ms to 175ms.
- **22% Catch-Rate Increase**: Increased actual fraud detection rate while reducing false user declines by 75%.
