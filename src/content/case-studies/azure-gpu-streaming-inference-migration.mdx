## Executive Summary

Legacy GPU inference endpoints running on over-provisioned static VM instances suffered from severe cloud cost overruns and manual deployment rollbacks during traffic spikes.

We led the migration to **Azure Kubernetes Service (AKS)** with custom queue-depth autoscalers, gRPC microservice streaming, and canary deployment rollbacks, cutting compute costs by 64% while maintaining 99.99% uptime.

---

## Technical Strategy

1. **Kubernetes Autoscaling**: Configured KEDA (Kubernetes Event-driven Autoscaling) based on real-time inference request queue length.
2. **gRPC Protocol Buffer Streaming**: Replaced HTTP/1 REST polling with HTTP/2 gRPC streaming, reducing protocol overhead by 40%.
3. **Canary Releases**: Configured automated canary deployments with instant health checks and zero-downtime rollbacks.

---

## Results

- **64% Cost Savings**: Eliminated idle GPU allocation during off-peak hours.
- **8-Minute Incident MTTR**: Reduced mean time to recovery from ~50 minutes to ~8 minutes.
- **Zero Downtime**: Flawlessly processed multi-region failovers during cloud region maintenance.
