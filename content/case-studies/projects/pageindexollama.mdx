# PageIndex Ollama

PageIndex Ollama is a privacy-first, local document tree indexing tool that processes large PDF and document hierarchies locally using Ollama models without sending sensitive data to third-party cloud APIs.

## Key Features
- **Hierarchical Document Indexing**: Preserves document structure, headings, and context windows.
- **Local Embedding Vector Store**: High-performance local similarity search.
- **Offline RAG Agent**: Generates accurate context-aware answers directly on local hardware.
